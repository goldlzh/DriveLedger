# 1.0.1 单实例更新记录

功能：同一账户、同一登录会话只启动一个新版正式查看器。再次打开时通知已有查看器调用现有的 Show / Normal / Activate 流程，恢复托盘中或最小化的窗口，然后退出新进程。窗口关闭仍隐藏到托盘，托盘“退出查看器”才释放所有权。后台采集服务与此锁独立。

更新方法：先在两个旧托盘图标上分别选择“退出查看器（采集服务继续）”，再从完整解压的1.0.1软件包运行安装.cmd。数据目录 D:\CDriveSpaceMonitor\Data 保留。完成后从桌面打开一次；后续重复打开只恢复同一个查看器。旧版1.0.0本身没有此协议，需退出一次。此开发任务没有操作或终止用户已有窗口，安装新版之前旧进程仍按旧行为运行。

实现与验证：每账户/会话的命名互斥量原子选主；本机同账户通信管道只接受固定激活命令、回复和接收确认，整体请求有超时。客户端向内核查询管道服务器PID后，向该进程授予前台请求权限。显式测试查看器使用隔离作用域。无数据库/采集算法变更，无新增运行依赖。普通查看不提权；不同提升等级的通知可能被系统拒绝，此时不会新建第二个窗口。

基线App23/23通过。8项新增跨进程测试在未实现时按预期失败（23/31），实现后31/31通过：重复启动、六个并发启动、启动延迟、正常退出重开、强制结束测试宿主后重开、隔离作用域、正式配置跨数据目录共享作用域、空闲连接超时。测试宿主属于测试程序，无新生产测试参数，也没有控制用户窗口。首次实现中直接同步读取异步ValueTask暴露错误，改用Task等待并补足接收确认后复测通过。

完整Core/Windows/App回归、发布/隔离采集与代码审阅结果将在交付前补充。测试确认了真实跨进程通信回调；最终用户窗口的显示流程沿用已验证的托盘恢复方法。未自动操作用户桌面验证前台焦点，不承诺绕过Windows前台焦点策略。

判断：同账户的不同Windows登录会话互不干扰；构建采用独立工作区保留原开发历史。代价是不同会话各可有一个查看器。升级交由现有安装器执行，开发期间保留用户控制，旧版窗口需手动退出；代价是在完成升级之前现有1.0.0仍可多开。
