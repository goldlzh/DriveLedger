C盘空间账本 1.0.0：使用说明

统计记录自动保存，CSV 只是需要时导出的副本，无需每天手动保存。

安装
1. 把 C盘空间账本-1.0.0-win-x64.zip 完整解压到 D:\C盘空间账本安装包。保留所有文件，不要直接在压缩包内运行，也不要解压到正式目标 D:\CDriveSpaceMonitor。
2. 双击 安装.cmd，按提示授予管理员权限。程序安装到 D:\CDriveSpaceMonitor\App，统计记录保存在 D:\CDriveSpaceMonitor\Data。此开发任务未替你执行正式安装。
3. 安装后从桌面“C盘空间账本”打开。正常查看无需管理员权限；后台服务开机自动采集，登录后启动托盘。发布包自带 .NET 运行时，无需另装 .NET。

每天怎么看
首次运行建立基准，原有文件不会算作当天新增，也无法追溯安装前历史。此后每 60 秒记录整盘空间、每 5 秒轮询文件变更，并定期核对元数据。
选择日期或日期范围，先看整盘净增长，再看目录排行。双击目录下钻，文件页查看具体路径和变化。父目录包含子目录，不能相加；硬链接不会重复计算，改名/迁移单独显示。
整盘净变化按“容量减空闲”的实际占用计算。目录/文件解释的是已归因部分，未解释差额和采集缺口会明确显示。“降级运行”表示部分连续性无法保证，重新扫描不一定能消除缺口。
目录统计、磁盘样本保留 365 天，文件变化明细保留 30 天。关闭窗口隐藏到托盘；退出查看器后后台仍继续。暂停/恢复/手动核对需要服务可连接。

CSV 保存在哪里
点击导出后可选择 D:\C盘空间账本.csv，或 D 盘上的其他普通文件夹。CSV 是当前查询结果的副本，不是后台数据库。不要保存到受保护的 Data 目录。
自动记录在 D:\CDriveSpaceMonitor\Data。备份请先停止服务，再完整复制整个 Data 文件夹；不要只复制其中一个数据库，也不要手动删除 WAL/SHM 辅助文件。
D 盘或数据目录不可用时程序会提示，不会改用 C 盘保存统计。

升级和卸载
升级前先从托盘退出查看器，从新的独立安装包运行 安装.cmd，保留数据。不要从已安装的 App 文件夹运行升级。
卸载请先退出托盘，再从独立安装包运行 卸载.cmd。只移除本软件配置和程序文件，保留 Data。运行中的卸载程序可能残留，退出后可按 README 手工处理。

验证与边界
94 项测试通过，并已做真实 SQLite、Windows 元数据、持续采集、临时服务宿主和发布程序隔离验证，详细结果见 验证记录.md。完整 C 盘首次扫描耗时、长期资源、正式安装/升级/卸载和真实开机流程尚未实测；安装后才开始实际生产观测。
本软件只读监测文件元数据，不读取文件内容，不自动清理任何文件。遇到受限元数据、未覆盖数据流或系统内部空间，可能无法逐文件完全解释。
软件源码见 source.zip；构建说明见其中 README.md。源码构建需要 .NET SDK 10.0.404，用户运行发布程序不需要 SDK。
